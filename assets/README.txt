Optional per-emotion living background (shown under the silk waves):

  Drop one file per mood into this folder, named by emotion id:
    joy.*  calm.*  love.*  release.*  ground.*  clarity.*  spirit.*  energy.*

  Formats (first match wins, in this order):
    .mp4  .webm  .jpg  .png  .webp

  Examples:
    assets/joy.mp4
    assets/calm.jpg
    assets/spirit.webm

Tips:
  - Keep them dark/soft (slow liquid light, aurora, ink in water).
  - Videos play muted + looped; stills breathe with a gentle zoom.
  - Soft crossfade (~3 s) on mood change; opacity stays low so silk waves remain the hero.
  - Local files only — no network during the show.
  - Leave this folder empty (or use ?media=0) for pure procedural visuals.
  - With no file for a mood, a soft procedural fog drift still lives under the waves.
